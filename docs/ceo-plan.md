## Vision

### 10x Check
The 10x version is a full regulatory engine: parse 27 CFR Parts 4, 5, and 16 into
machine-checkable rules, return pass/review/fail with citations per rule (what
COLAClear ships commercially — 34 checks per label). It would turn "does the label
match the form" into "is the label legal." Out of scope for a take-home judged on
a working core; recorded as the trajectory the architecture should not block:
keep the rules engine a pure function over extracted fields so new rules are
additive files, not rewrites.

## Accepted Scope (merged into PLAN.md)
All four items are now specified in PLAN.md with milestone assignments:
- Per-field evidence quotes (M2): extraction schema returns `{value, verbatim_text, readable}` per field; single and batch-detail result UIs render "Label says <verbatim> / Application says <value>". Sizing note: schema + UI plumbing makes this closer to M than S.
- Word-level warning diff view (M2): tokenize on whitespace after the comparator's normalization, case-sensitive token compare; prefix-caps failure reported as its own line.
- ABV↔Proof cross-check (M2): label-internal consistency check (proof = 2×ABV), distinct from the existing label-vs-application ABV comparison; disagreement → dedicated MISMATCH row showing both parsed values.
- Sample-label demo button (M1): bundled clean-match, deliberate-mismatch, and bad-photo examples with prefilled data.
