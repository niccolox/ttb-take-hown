## Affected Pages/Routes
- `/` (single screen, master-detail) — upload, sample chooser, form, results detail; verify <5s warm on deployed URL
- `POST /api/verify` — single-label verification; every 4xx path (type, size, pixels, corrupt, rate limit)
- Job API (`/api/jobs…`) — batch submit/status/result/cancel semantics
- `/healthz` — ready only after model warmup with live worker

## Key Interactions to Verify
- "Try a sample" five named proof points: clean match / obvious mismatch / title-case warning trap / bad photo → review / small batch with one failure
- Verify button disabled in-flight; empty-form inline prompt; Enter submits; form persists via "Check another label"
- Batch: rows never reorder while streaming; per-row retry; "Cancel waiting checks" actually cancels server-queued items; apply-to-all confirmation + undo; completion banner counts + filter
- Evidence crop click-to-enlarge dialog showing region on full label; keyboard reachable
- Warning grouped check: three subchecks, disclosure diff with labeled language

## Edge Cases
- EXIF-rotated iPhone photo (90/180/270); HEIC upload; 20MB PNG; 0-byte file; PDF renamed .png; cat photo (text-mass gate → "doesn't look like a label", not confident MISMATCH)
- Stacked two-line brand name ("STONE'S / THROW"); similar-but-different brand ("OLD TOM DISTILLING CO."); 3-char brand
- Title-case "Government Warning"; one-word-substituted warning; correct warning on blurry region → unable-to-verify (not false mismatch)
- Proof-only label vs ABV application value; "45%" vs "45.0%"; OCR-mangled "%"
- CSV manifest: BOM, CRLF, semicolons, quoted commas, duplicate filenames, missing columns, 10k-row cap
- 3× pool-size concurrency → clean 429s, no cross-request bleed; kill worker mid-batch → row NEEDS REVIEW(system), batch completes

## Critical Paths
- Clone → docker compose up → sample verify < 5s (evaluator minute one)
- Upload real bottle photo → readable verdicts with evidence crops → print report
- 300-label batch: time-to-first-result seconds, completion ~minutes, one failed row retried individually, CSV export opens clean in Excel
