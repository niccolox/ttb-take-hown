# UX Audit — 2026-08-03 (screenshot-driven, live app)

Method: headless-Chrome walkthrough of the running app (empty state,
samples menu, loaded, checking, settled, results). Strengths: correct
left-to-right workflow (triage → edit → evidence); strong settled-state
hierarchy (sign-off banner, two-stage timing, per-field rows with crops);
honest state language (·agent markers, withheld provisionals).

Findings (P = priority):
- P1 Contradictory glyph: every decided chip prefixes "✓" — including
  "✓ Fail ·agent". Root cause: decided-check in the loz template.
  Fix: per-family glyphs (✓/👁/✗), decided-ness already carried by ·agent.
- P1 Empty first-run dead end: three empty cards, all actions hidden in
  nav menus. Fix: empty-state hero in Applications (choose images / try a
  sample).
- P1 Identical batch rows indistinguishable: brand-only titles; filename
  only visible after selecting. Fix: filename subtitle on rows.
- P2 Wine fields shown to spirits (vintage/appellation/varietals always
  render; Verify pushed below fold). Fix: conditional on beverage type.
- P2 Image toolbar ragged (rotate / add-back stacked, mixed styles).
  Fix: one button-group row per panel.
- P2 Evidence crops too small (~90px) for the product's highest-value
  artifact; zoom affordance only discoverable via cursor. Fix: larger
  crop cell + visible magnifier.
- P3 Verdict context scrolls away mid-review. Fix: sticky slim banner in
  Selected label.
- P3 Filter list tall (8 rows before first label). Fix: compact grid.
- P3 Nav label "Start a check" hides CSV batch import. Fix: naming.
